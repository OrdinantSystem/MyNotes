Fifteen figure variants and four activity presets use the existing public ReasoningFigure/Interactive module API. The gallery supplies a second independent layers instance. No shared component contract, registry, dependencies or sibling sites change.

The EN/DE lesson preserves all eight acts and four transfer questions: reality versus belief; fallible justification; JTB as a proposed necessary-and-sufficient analysis; Russell's clock versus Gettier's later challenge; epistemic luck and nearby moments; repair, discovery of a defeater, independent evidence actually used, unused available evidence and dependent copies; the invalid converse about odd numbers and primes; the full square-root divisor proof for seven; and three qualified diagnostic questions. Knowledge is deliberately not a computed Boolean. Justification remains explicitly conditional on a plausible fallible understanding; reliability is not offered as a complete theory or an infallibility requirement.

The existing families do not model the independent actual time, accepted time, mechanism, awareness, evidential availability and basis of belief required here. A bounded clock-specific model therefore sits behind the existing wrappers, using canonical tokens, escaped SVG, native labeled controls and shared math rendering. Evidence offers six source-grounded situations at 16:30/16:31. It makes no automatic knowledge attribution; all explanatory qualifications stay visible.
