# AoR 63 · Final proof workshop

Owns the bilingual `final-proof-workshop` lesson, ten localized figures and six activities through the public module dispatcher. Pure mathematics lives in model.ts; rendering reuses MathText/KaTeX, escapeSvg and canonical semantic tokens. No shared registry, dependency or public component contract changes.

The existing parity/congruence illustrations cannot express this workshop's combination of a conserved tile partition and two editable local drafts. The bounded local module uses the established module mechanism, native controls and semantic figure styles. It introduces no simulation framework.

Numeric activities: signed odd n ∈ [−19,19], consecutive k ∈ [−6,6], geometric/layer k ∈ [0,6], numeric and range alternatives, endpoint buttons, reset and local announcements. Geometry preserves coordinate identities across square/rectangle/pair views. Four congruent rotated rectangles cover every noncentral tile exactly once. Dominoes follow each rectangle's even dimension; corresponding dominoes form complete groups of eight. The first such group is marked ①; no movement or loss is simulated. Empty geometry k=0 is valid. Negative odd inputs are covered through the explicit absolute-value argument in prose.

Draft activity: independent first/revised textareas, three progressive hints, seven unscored self-review checks, explicit copy-first-to-revision action, working clipboard copy with fallback feedback and explicit clear. Both fields are capped at 12,000 characters. Hints/checks never overwrite drafts. Nothing is stored persistently or submitted. Reloading clears drafts. Copying the first draft into revision deliberately replaces only the revision and is labeled accordingly. No automated proof validation or mastery scoring.

Examiner: four imaginary submissions, three choices each, deliberate explanation reveal, independent selections and reset. A finite example list, false 4k divisibility, scope error and concise valid proof are distinguished. C's source wording “all integers” both omits the negative-odd extension and incorrectly includes even integers; the feedback makes both issues explicit.

EN/DE contain the full signed-integer algebraic proof, explicit integer witnesses, rectangle and ring proofs, domain extension, four standards, revision prompts, side-by-side comparison, exhaustive even-square proof, classification {0,1,4}, impossibility application and reflection. Source timestamps, video directions, self-promotional ratings and claimed assessment of previous episodes are not learner material. Source gold becomes a numbered outlined central unit using canonical tokens. The point rubric is adapted to unscored self-review under the site's no-mastery-scoring contract.
