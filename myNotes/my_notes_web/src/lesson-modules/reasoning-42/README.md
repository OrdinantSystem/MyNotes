Three activities use pure local state:

- `rankings`: four source metrics, stable learner identities and explicit competition ranks (A/C tie at rank 1 in completion). Changing the metric changes only the ordering criterion. Percentages from unlike tasks are not averaged. Initial state is completion; reset is instance-local.
- `sorting`: three proposed outputs for [3,3,1]. Inspect distinguishes nondecreasing order and multiset preservation. The hypothetical bad output refutes a universal claim only if actually produced by the claimed algorithm on an admissible input. No algorithm is executed. Empty selection disables evaluation. Changing context or selection hides stale evaluation. No numerical scoring or submission.
