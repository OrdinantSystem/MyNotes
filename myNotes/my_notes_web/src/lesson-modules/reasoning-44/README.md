## Models and limits

Four optional activities: unbiased Fisher–Yates split into 30/30 without preparation balancing or rejected draws; protocol time/support repair; selective removal of four known fictional scores; six native reference-answer disclosures with reveal/close/reset. Controls have keyboard alternatives, stable focus, local reset and concise polite status. The gallery automatically includes independent instances.

The randomization activity is a separate 60-student illustration, not a resampling of the 100-person main experiment. It models assignment only, not outcomes. The protocol activity changes interpretation, never recalculates the fixed 68/84 scores. Repairing these two features is not a causal guarantee. The adherence picture retains 50/50 assignment, distinguishes 55/45 received methods, and is separate from 46/50 vs 35/50 completion. Missing outcomes are unknown, never zero.
